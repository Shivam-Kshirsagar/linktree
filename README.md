# Linktree – Link Management Web Application

A Linktree-inspired web application built using Next.js, React, JavaScript, and MongoDB. This project allows users to manage and share multiple links through a single platform.

## 🚀 Features

- Modern and responsive user interface.
- Navigation bar with multiple sections.
- Templates section.
- Marketplace section.
- Discover section.
- Pricing section.
- Learn section.
- MongoDB database connectivity.
- Reusable React components.

## 🛠️ Tech Stack

- Frontend: Next.js, React.js
- Programming Language: JavaScript
- Styling: CSS, Tailwind CSS
- Database: MongoDB
- Backend: Next.js
- Version Control: Git & GitHub

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Shivam-Kshirsagar/linktree.git
```

### 2. Navigate to Project Directory

```bash
cd linktree
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the root directory.

Add your MongoDB connection string:

```env
MONGODB_URI=your_mongodb_connection_string
```

### 5. Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

http://localhost:3000
